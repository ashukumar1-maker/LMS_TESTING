# Cursor Bugbot Rules

Open and apply the project-wide review rules in [`../REVIEW.md`](../REVIEW.md).

Always check code, contract, workflow, and configuration changes against nearby docs and generated contract files. Flag stale or missing documentation updates.

When changed files are under `backend/`, also apply [`../backend/REVIEW.md`](../backend/REVIEW.md). When changed files are under `frontend/`, also apply [`../frontend/REVIEW.md`](../frontend/REVIEW.md).
