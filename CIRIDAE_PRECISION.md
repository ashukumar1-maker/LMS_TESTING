# Ciridae Precision

Ciridae Precision is the visual language for Ciridae software: exact, modern, serious, and built for teams operating at the frontier of AI.

We build AI operating systems for businesses. Our interfaces should feel like mission-critical infrastructure: calm, fast, intelligent, and durable. The design should not call attention to itself through decoration. It should earn trust through clarity, restraint, and precision.

## What It Should Feel Like

- **Minimal, not empty.** Interfaces should be quiet and focused, but dense enough for real operators doing repeated work.
- **Monochrome-first.** Black, white, and calibrated grays are the core brand expression. Color is used sparingly and only when it carries meaning.
- **Cutting-edge through restraint.** The product should feel modern because it is crisp, exact, responsive, and deeply considered, not because it uses trendy effects.
- **Customer-neutral.** The system should work across customer domains without fighting their context or over-imposing our brand.
- **Operationally serious.** Ciridae software should feel like a control surface for important work: structured, trustworthy, and built to scale.

## Visual Principles

- **Precision over decoration.** Use alignment, hierarchy, spacing, borders, and type discipline before adding visual flourish.
- **Clarity over personality.** The UI should make complex systems understandable without becoming generic or bland.
- **Density with air.** Favor scan-friendly layouts, tables, panels, sidebars, tabs, and forms with enough breathing room to avoid fatigue.
- **State through tone.** Show hierarchy and interaction with subtle shifts in foreground, background, border, and shadow.
- **Motion with purpose.** Motion should clarify state changes and make the interface feel responsive. It should never feel ornamental.

## Core Aesthetic

The baseline product palette is monochrome: near-black foregrounds, near-white surfaces, disciplined gray borders, and muted gray secondary text. Dark mode should feel native and intentional: graphite surfaces, off-white text, and quiet separation.

Primary actions should feel decisive. Secondary actions should recede. Status colors should be desaturated and operational, reserved for semantic states such as success, warning, info, and destructive actions.

Typography should feel precise and technical without becoming cold. Ciridae Precision uses Host Grotesk as the product voice: stable, machined, neutral, and built for interface work. Headings stay lighter than typical SaaS UI, uppercase is restrained to metadata and system labels, and IBM Plex Mono is reserved for identifiers, timestamps, code, and numeric operational data. Product type should optimize for legibility, scanning, data density, and repeated use; brand display type should not dominate routine application screens.

Surfaces should feel engineered: compact radii, thin borders, restrained shadows, and clear elevation only where hierarchy requires it. The default shadcn/Tailwind tokens and stock components should already express this, so builders can move quickly without reinterpreting the system.

The system should be easy to follow by default. Shared components should encode density, shape, focus, state, and navigation behavior so agents and engineers can build with normal shadcn and Tailwind habits while still landing in the Ciridae Precision aesthetic.

## What To Avoid

- Decorative gradients, glows, or futuristic effects.
- Heavy shadows, blur effects, scale-heavy motion, or oversized focus rings.
- Colorful SaaS palettes.
- Oversized rounded cards or playful softness.
- Marketing-page composition inside application surfaces.
- Visual noise that makes customer workflows harder to scan.
- Strong brand color dominance in routine product UI.

## The Standard

Ciridae software should look and feel like it was built by people who care about the details because the work matters. The interface should be quiet until it needs to speak, sharp when it does, and precise everywhere.
